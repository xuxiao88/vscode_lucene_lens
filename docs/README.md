## 文档维护

- 文档使用中文编写；类名、命令、协议字段等技术标识保留英文。
- 设计变更应记录“为什么改变”，不能只覆盖结论。
- 文档中的命令、目录和配置项应与代码保持一致。
- 新增文档后，更新本页以及仓库根目录的 `AGENTS.md`。
